# Bazardor Daily Market Tracker

A clean, high-performance web application designed to track and display real-time commodity prices, market trends, and daily grocery rates at a glance. Built with a modern tech stack, the platform transforms raw price index data into intuitive, highly scannable visual indicators for daily essentials.

## 🛠️ Technologies Used

* Next.js: React framework for server-side rendering, optimized performance, and robust routing.
* TypeScript: Static typing to ensure code reliability, better developer tooling, and fewer runtime errors.
* MongoDB: NoSQL database used for flexible, scalable storage of daily commodity prices, market data, and user profiles.
* Better Auth: Comprehensive authentication framework providing secure, seamless user login, session management, and database integration.
* Tailwind CSS: Modern utility-first CSS framework for custom badges, grid systems, and rapid layout design.
* React Icons: Lightweight, customizable icon sets providing crisp visual indicators across the UI components.
* Figma: The primary design utility used to create structural wireframes and visual UI blueprints.

## 📱 Features

* Daily Market Price Overview: A comprehensive dashboard featuring real-time grocery, vegetable, meat, and oil prices.
* Dynamic Price Trend Badges: Visual percentage indicators that clearly flag whether an item's price has gone up, down, or remained stable.
* Real-time Live Ticker: An interactive Marquee horizontal scroll at the top showcasing instant, breaking price updates and alerts.
* Secure User Authentication: Implemented via Better Auth, allowing users to safely log in, save favorite items, or manage dashboard views.
* Persistent Database Storage: Backed by MongoDB to efficiently manage historical price records, track trends over time, and securely store user data.
* Categorized Price Grids: Items are dynamically sorted into distinct sections like "Prices Up Today" and "Prices Down Today" for effortless navigation.
* Responsive Multi-Column Layout: A fully responsive grid layout tailored to ensure text scannability and perfect rendering across desktop, tablet, and mobile displays.
